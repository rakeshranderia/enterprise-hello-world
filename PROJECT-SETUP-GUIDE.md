# Repository Setup Guide

This file is intended to help create the GitHub repository and can remain public if desired.

## Recommended Repository Name

`enterprise-hello-world`

## Recommended Description

> A deliberately simple application demonstrating the full delivery lifecycle: requirements, Git, CI, IaC, testing, UAT, release, hypercare and BAU transition.

## Suggested Topics

- devops
- cicd
- infrastructure-as-code
- bicep
- python
- flask
- uat
- release-management
- incident-management
- technology-leadership

## Setup Order

1. Create public repository `enterprise-hello-world`.
2. Add all files from this package.
3. Commit:
   `Initial enterprise delivery lifecycle`
4. Push to `main`.
5. Confirm CI and IaC workflows run.
6. Create the GitHub Project using `docs/03-delivery/github-project-setup.md`.
7. Create real issues from the backlog.
8. Follow `docs/03-delivery/demo-scenario.md`.
9. Create a genuine `v1.0.0` release only after completing the lifecycle.
10. Link the completed project from the GitHub profile and website only when it has enough real history to be useful.

## Important

Do not fabricate historical commits, fake collaborators, fake approvals or fake production incidents.

The project is strongest when the demonstration is transparent.
