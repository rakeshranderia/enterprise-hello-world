# Non-Functional Requirements

## Security

- No secrets in source control.
- HTTPS should be enforced in the Azure example.
- Minimum TLS 1.2 in the Azure example.
- Dependencies should be reviewed.
- Lightweight security scanning should run in CI.

## Reliability

- Health endpoint available.
- Recovery steps documented.

## Maintainability

- Source code version controlled.
- Automated tests included.
- Documentation stored with code.

## Supportability

- Operational runbook provided.
- Escalation and ownership documented.
- Known issues and workarounds tracked.

## Cost

- No cloud deployment is required for the demonstration.
- Any real Azure deployment must be consciously approved because it may incur cost.
