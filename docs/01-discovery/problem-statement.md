# Problem Statement

## Problem

A simple application is often easy to build, but real technology delivery involves considerably more than writing code.

Delivery teams need to manage:

- requirements;
- scope;
- source control;
- testing;
- security;
- release;
- infrastructure;
- operational readiness;
- documentation;
- incidents;
- handover.

## Demonstration Objective

Build the smallest possible application while demonstrating the full lifecycle around it.

## Application Outcome

A user opens the service and receives:

```text
Hello World
```

A monitoring process can call:

```text
/health
```

and receive a healthy status.

## Project Outcome

Demonstrate that even a trivial service can be:

- specified;
- version controlled;
- tested;
- reviewed;
- deployed using repeatable infrastructure;
- released;
- monitored;
- supported;
- transitioned to BAU;
- improved after an incident.
