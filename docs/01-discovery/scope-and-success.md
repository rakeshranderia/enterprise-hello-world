# Scope & Success Criteria

## In Scope

- Python web service;
- Hello World endpoint;
- health endpoint;
- automated tests;
- GitHub Actions CI;
- Azure Bicep example;
- documented UAT;
- release/cutover process;
- operational runbook;
- hypercare and incident simulation;
- BAU handover.

## Out of Scope

- production-grade authentication;
- database;
- customer data;
- high availability;
- paid Azure deployment;
- complex application functionality.

## Success Criteria

The project is successful when:

- `/` returns `Hello World`;
- `/health` reports healthy;
- automated tests pass;
- CI passes on pull requests;
- Bicep compiles;
- UAT evidence exists;
- release readiness is completed;
- an authentic bug-fix lifecycle is demonstrated;
- operational documentation is complete;
- a release can be handed to BAU.
