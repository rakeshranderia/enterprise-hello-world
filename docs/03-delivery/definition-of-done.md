# Definition of Done

An item is complete when:

## Functional

- [ ] Acceptance criteria met
- [ ] Required functionality works

## Quality

- [ ] Unit tests pass
- [ ] CI passes
- [ ] UAT completed where required

## Security

- [ ] No secrets added
- [ ] Security scan passes
- [ ] Security impact considered

## Documentation

- [ ] Relevant documentation updated
- [ ] Known limitations recorded

## Operations

- [ ] Monitoring impact considered
- [ ] Runbook updated if needed
- [ ] Recovery/rollback understood
