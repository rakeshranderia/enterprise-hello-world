# GitHub Project Setup

Create **one GitHub Project** named:

> Enterprise Hello World — Delivery Lifecycle

The board demonstrates delivery flow rather than simply tracking code.

## Suggested Fields

### Status

- Backlog
- Ready
- In Progress
- Review / Test
- Ready for Release
- Hypercare
- Done

### Priority

- P1
- P2
- P3

### Type

- Requirement
- Feature
- Bug
- Security
- Documentation
- Release
- Operations

## Suggested Initial Items

Create these as real GitHub Issues and add them to the Project:

1. Define Hello World acceptance criteria
2. Implement Hello World endpoint
3. Add health endpoint
4. Add automated unit tests
5. Add CI workflow
6. Add Bicep infrastructure definition
7. Complete UAT
8. Prepare release readiness
9. Execute simulated go-live
10. Complete hypercare
11. Simulate production defect
12. Complete PIR and BAU handover

## Why Use a Project Board?

The repository shows **what** exists.

The Project board shows **how work moves**:

**Backlog → Delivery → Test → Release → Operate**
