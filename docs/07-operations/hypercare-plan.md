# Hypercare Plan

## Duration

Demonstration period: one short post-release observation window.

## Monitor

- root endpoint;
- health endpoint;
- bug reports;
- CI/release health.

## Exit Criteria

- no critical defects;
- service stable;
- runbook validated;
- known issues owned;
- BAU handover complete.
