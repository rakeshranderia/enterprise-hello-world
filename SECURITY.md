# Security

## Scope

This repository contains a deliberately simple demonstration application and public delivery artefacts.

Do not commit:

- passwords;
- API keys;
- client secrets;
- certificates;
- private keys;
- tenant identifiers that should remain private;
- real customer or employer data;
- sensitive screenshots or logs.

## Reporting

If a security issue is identified in the example code, raise a GitHub issue without including sensitive exploit data.

## Security Principles

- least privilege;
- no secrets in source;
- dependency review;
- input validation where applicable;
- automated security checks;
- controlled deployment;
- logging and monitoring;
- explicit risk acceptance for known exceptions.
